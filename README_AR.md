# برنامج إدارة محل البلايستيشن — نسخة بداية

## المميزات الحالية
- واجهة عربية.
- 6 أجهزة أولية، ويمكن إضافة أجهزة أخرى.
- الجهازان 1 و5 مخصصان للمباريات.
- مؤقت 7 دقائق، وإمكانية بدء الشوط الثاني يدويًا.
- تنبيه صوتي واهتزاز عند انتهاء المؤقت.
- تغيير أسماء الأجهزة وحفظها.
- كلمة مرور عند فتح التطبيق وإمكانية تغييرها.

## بناء APK من الهاتف عبر GitHub
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع محتويات هذا المجلد (لا ترفع ملف ZIP نفسه).
3. افتح تبويب Actions.
4. اختر Build PS Shop APK ثم Run workflow، أو انتظر انتهاء البناء بعد الرفع.
5. افتح نتيجة البناء الناجح، ثم نزّل Artifact باسم PSShop-debug-APK.
6. فك ضغط الملف الذي نزّلته، ثم ثبّت app-debug.apk.

ملاحظة: هذه نسخة بداية تحتاج اختبارًا على الهاتف قبل الاعتماد عليها في العمل اليومي.
